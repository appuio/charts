APPUiO Helm chart repository

Helm charts for APPUiO, the Swiss container platform.

Add the repository

helm repo add appuio https://charts.appuio.ch
helm repo update
helm search repo appuio

Then install a chart

helm install my-release appuio/<chart> --values values.yaml

More information

  • github.com/appuio/charts — chart sources, values reference and issues
  • index.yaml — the repository index, which is what Helm reads
  • docs.appuio.cloud — APPUiO Cloud documentation
